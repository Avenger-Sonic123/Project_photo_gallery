# Photo Gallery

A browser-based photo gallery with a carousel.

**Repository created:** 2021-03-09  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2021-03-08

## Features and implementation

- Bootstrap carousel with previous/next navigation.
- Image-based gallery layout.
- Custom stylesheet.

## Technologies

HTML, CSS, Bootstrap, jQuery.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |
| [`style.css`](style.css) | Page styling |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/Project_photo_gallery.git
cd Project_photo_gallery
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Use the carousel arrows to navigate the images.

## Current status and limitations

Remote images and CDN libraries may no longer load.
